Panduan Format File

  • Format File: Excel (.xlsx, .xls) atau CSV
  • Kolom Wajib: Title (Judul) dan Content (Isi Berita)
  • Kolom Opsional: Category (Kategori), Link, dan Time (Waktu)
  • Encoding: UTF-8 (untuk file CSV)
  • Ukuran Maksimal: 50 MB per file
  • Deteksi Duplikasi: Sistem otomatis mendeteksi berita yang sudah ada
  • Kategori Valid: teknologi, otomotif, sport, lifestyle, finance, health, education, nasional, travel
